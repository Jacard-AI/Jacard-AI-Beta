# Security Policy

## Reporting A Vulnerability

Do not open public GitHub issues for security vulnerabilities.

Use GitHub private vulnerability reporting for this repository:

- [Report a vulnerability privately](https://github.com/Jacard-AI/Jacard-AI-Beta/security/advisories/new)

Include:

- affected URL or feature
- steps to reproduce
- impact
- any workaround or mitigation you discovered

If private vulnerability reporting is unavailable for any reason, contact the maintainers through the repository owners directly and avoid posting exploit details publicly.
