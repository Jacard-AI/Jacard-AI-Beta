# Contributing

This repo is for tracking Jacard beta issues and product feedback.

## Before You File

- Search [open issues](https://github.com/Jacard-AI/Jacard-AI-Beta/issues) for duplicates.
- If you find a similar report, add your repro details there instead of opening a new issue.

## Write Better Titles

Good issue titles are short, specific, and scoped to one problem.

- Better: `Jacard View preview stays blank after page generation completes`
- Better: `Mobile composer jumps upward on iPhone Safari after keyboard close`
- Avoid: `Site broken`
- Avoid: `Lots of issues`

## Share Links vs Screenshots

Use a share link when the generated answer page or conversation state matters.

- Attach a share link if the issue depends on the actual prompt, generated view, or page state.
- Attach screenshots when the issue is primarily visual, layout-related, or timing-sensitive.
- If you have both, include both.

## Public Data Warning

This is a public tracker.

- Do not post API keys, auth tokens, private documents, or personal data.
- Only include prompts, uploads, and screenshots that are safe to share publicly.
- If the problem involves a security vulnerability, use the private path in [SECURITY.md](SECURITY.md) instead of a public issue.
